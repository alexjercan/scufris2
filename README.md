# Scufris

Scufris is a Pi-based assistant with delegated project workflows, a background
service that owns the conversation, and a Linux desktop companion for voice,
conversation, and widgets.

## Quickstart

Run the complete stack from this checkout in an isolated staging environment:

```bash
nix run .#staging -- up
```

Staging uses the current Pi login, keeps its own sessions and runtime paths, and
runs beside any deployed Scufris. Press `Ctrl+C` to stop it.

For a Home Manager deployment that consumes the existing `ai-tools-api` on
port 10300:

```nix
programs.scufris = {
  enable = true;
  # ctlPackage = inputs.scufris.packages.${pkgs.system}.scufris-ctl;

  # Use the Pi package already configured by this Home Manager deployment.
  service = {
    enable = true;
    # package = inputs.scufris.packages.${pkgs.system}.scufris-service;
    agent = {
      piPackage = config.programs.agents.pi.finalPackage;
      projectRoots = ["~/personal" "~/work" "~/third-party"];
      # Leave package unset to render the launcher from the two options above.
      # package = <custom-agent-launcher>;
    };
    sessionDirectory = "${config.xdg.dataHome}/scufris/sessions";
  };

  desktop = {
    enable = true;
    # package = inputs.scufris.packages.${pkgs.system}.scufris-desktop;

    # Consume the one shared API instead of starting a fallback service.
    aiToolsApi = {
      manage = false;
      baseUrl = "http://127.0.0.1:10300";
    };

    speech.enable = true;
    transcription.endpoint = null; # Derive it from aiToolsApi.baseUrl.

    hotkey = "Super+D";
    cancelKey = "Super+Escape";
    stopKey = "Super+Delete";

    chatCommand = null;
    todayCommand = null;
    denPath = null;
    macrosDatabase = null;
  };
};
```

The module supplies the `scufris-ctl`, service, agent launcher, and desktop
packages from the pinned flake. Their package options remain available for
advanced overrides. The read-only `serviceName`, `resolvedEndpoint`, and
`restartCommand` options are generated by the module.
